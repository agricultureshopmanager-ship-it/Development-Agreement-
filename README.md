# ShopSteward 3D — Cyber Spatial HUD & Shop Operating System

A high-performance, responsive 3D website built for **ShopSteward**. Features a real-time scroll-driven 3D WebGL transformation engine, brutalist cyber-minimalist typography, and interactive tactile shop modules.

---

## 🌟 Key Features

1. **Scroll-Driven 3D WebGL Transformation (`Three.js`)**:
   - **Hero Stage**: Central multifaceted Obsidian Terminal Monolith with a glowing 3D Holographic Steward Key and dual cybernetic laser rings.
   - **Scroll-Triggered Explosion**: As visitors scroll down the page, the 3D core rotates and projects exploded holographic spatial panels (POS Billing Live Screen, AI Neural HUD, Udhaar Ledger) floating in true 3D space around the camera.
   - **Reactive Particle Wave Grid**: Interactive floor wave matrix and ambient neon stardust responding to cursor/touch inertia.
   - **Optimized for Mobile & Desktop**: Caps device pixel ratio to 2, with auto-throttling via `IntersectionObserver` when scrolled or minimized.

2. **Tactile Interactive Modules**:
   - **Interactive Spooling Thermal Receipt POS**: Dynamic billing calculator that animates and spools a realistic paper receipt with barcode, timestamp, subtotal, and grand total.
   - **Web Audio API Synth Engine (SFX)**: Toggleable tactile sound synthesizer (`⚡ SFX: ON/OFF`) generating zero-latency futuristic feedback tones on buttons and tabs without external audio files.
   - **AI Steward Command Terminal**: Preset prompt chips and custom input fields with real-time streaming answer simulation.
   - **Niche Architecture Matrix**: Dynamic sector switcher (Agriculture, Grocery, Hardware, Wholesale, Textile, Electronics) adjusting unit and workflow specifications on the fly.
   - **Interactive 3D Perspective Tilt**: Mouse and touch tracking perspective rotation with dynamic sheen.

## 🚀 How to Run Locally

Because this project is built with pure standards-compliant HTML5, CSS3, and modern JavaScript:
- **Instant Preview**: Double-click `index.html` in your file manager to open it in your browser.
- **Local Dev Server** (optional):
  ```bash
  # With Python (if installed)
  python -m http.server 3000

  # With Node.js (if installed)
  npx serve .
  ```

## 🌐 Free 1-Click Deployment Options

### Option 1: GitHub Pages
1. Push this folder to a GitHub repository.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and root `/`, then click **Save**.

### Option 2: Vercel / Netlify / Cloudflare Pages
- Drag and drop this folder directly into the dashboard of [Netlify Drop](https://app.netlify.com/drop) or [Vercel](https://vercel.com) to deploy instantly worldwide.
